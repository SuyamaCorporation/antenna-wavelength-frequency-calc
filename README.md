# アンテナ波長・周波数・エレメント長計算機

周波数からダイポール・モノポール・八木アンテナ等の各種アンテナエレメント長を計算する無線工学ツール。

## 機能

- 周波数入力（Hz/kHz/MHz/GHz の単位選択）
- 波長λ=c/f の計算
- アンテナ種別ごとのエレメント長を一覧表示
  - λ/2 ダイポール、λ/4 モノポール、5/8λ垂直、λ全波長ループ、3/2λダイポール、八木アンテナ参考値
- 逆計算（エレメント長→周波数）タブ対応
- 短縮率スライダー（80〜100%）→実際の短縮効果考慮
- アマチュア無線バンドプリセット一覧（12バンド）
- アマチュアバンド判定（逆計算結果が対応バンドを表示）

## 技術仕様

- バニラJS / Tailwind CDN
- 光速 c = 299,792,458 m/s を使用
- XSSガード: escHtml() による innerHTML 無害化
- 全インタラクティブ要素に aria-label 付与
- レスポンシブ対応
